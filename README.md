# Library Management System

A simple Python library management system that allows users to borrow and return books.

## Features
- Borrow and return books
- Track book availability
- Auto-generated unique IDs for books and users
- Timestamps for created and updated records
- Export data to JSON files

## How to Run
```bash
python library.py
```

## Files Generated
- `book1.json` — book record
- `user1.json` — user record
- `records.json` — all books and users

## Built With
- Python 3
- `uuid`, `datetime`, `json` (standard library)
